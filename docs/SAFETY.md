# 数据安全原则

1. 源介质默认只读；恢复文件必须写入其他目录或其他磁盘。
2. 扫描、预览和恢复默认完全在本地执行。
3. 不记录文件正文，不收集恢复内容，不上传扫描结果。
4. 所有扫描结果都标注为候选，不把文件签名命中等同于文件完整。
5. 加密数据只在用户提供合法密码或系统已解锁的情况下处理。
6. 后续物理磁盘模块必须独立审计，写入系统调用必须从扫描进程中隔离。
7. 遇到机械异响、频繁掉盘或大量 I/O 错误时停止软件扫描，建议先制作镜像或交由专业实验室处理。
8. macOS 原始磁盘授权只接受 `/dev/rdisk` 加数字的整盘路径，并通过系统 `authopen` 申请只读句柄；不申请写权限。
9. 启动盘扫描只在用户明确确认后启用，界面必须告知运行中的系统写入、APFS 加密和 SSD TRIM 风险。
