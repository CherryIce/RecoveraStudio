# 产品范围与路线图

## M0：整盘文件雕刻（当前）

- Flutter 跨平台项目和桌面工作台。
- macOS 整块物理磁盘检测、启动盘风险确认与系统只读授权。
- Windows 物理磁盘检测；管理员句柄桥接仍待完成。
- 整盘及磁盘镜像只读分块扫描。
- JPEG、PNG、PDF、ZIP、DOCX、XLSX、PPTX。
- 预览、单项恢复、批量恢复。
- 合成镜像自动测试。

## M1：文件系统级桌面恢复

- Windows 原生只读权限提升。
- 磁盘、U 盘、SD 卡镜像制作。
- GPT/MBR、FAT32/exFAT、NTFS 元数据解析。
- GPT/MBR 分区识别、快速扫描、深度扫描、暂停和任务断点。
- 恢复概率与结构校验，不以“找到签名”冒充完整文件。

## M2：Apple 与 Android 备份

- Finder/iTunes 本地备份索引和加密备份解锁流程。
- 照片、联系人、短信、附件和 SQLite/WAL 数据解析。
- Android SAF/MediaStore 合法授权数据与本地备份导入。
- 明确区分“备份中恢复”和“设备底层恢复”。

## M3：专业恢复能力

- APFS、HFS+、ext4、F2FS。
- 分片 JPEG/视频重组与 MP4/MOV 容器修复。
- 坏盘镜像、跳读策略、哈希和证据日志。
- Rust/C++ 核心性能优化与模糊测试。

## 不做的承诺

- 不承诺恢复已经被覆盖或经 TRIM 清理的数据。
- 不绕过设备密码、激活锁或磁盘加密。
- 不把普通 iOS App 描述成可以扫描整台 iPhone/iPad。
- 不在恢复前向源介质写入修复数据。
